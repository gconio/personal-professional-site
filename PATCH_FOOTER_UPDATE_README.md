# Patch footer — data aggiornamento contenuti

## File incluso

## Modifica

Aggiunge nel footer la riga:

## Applicazione

Copia il file nella root del progetto `personal-professional-site-starter`, sovrascrivendo quello esistente.

Poi esegui:

```powershell
npm run build
npm run dev
```

Verifica il footer in locale e poi pubblica con commit/push.
