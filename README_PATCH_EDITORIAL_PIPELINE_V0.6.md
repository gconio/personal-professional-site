# Lab4Int Editorial Pipeline v0.6

Milestone di consolidamento della dashboard editoriale.

## Modifiche

- separazione tra revisioni sostanziali e completamento metadati;
- coda operativa meno rumorosa, con default sulle revisioni;
- collegamenti diretti ai file sorgente;
- motivazione dell'intervento visibile;
- conteggio degli elementi filtrati;
- esportazione CSV;
- stampa della dashboard;
- nessuna nuova dipendenza npm.

## Validazione

Eseguire:

```bash
npm run editorial:check
```
