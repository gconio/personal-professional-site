# Roadmap

## Fase 1 — MVP pubblicabile

- Confermare nome e sottotitolo del sito.
- Sostituire `Nome Cognome` nei file.
- Aggiornare email nella pagina Contatti.
- Inserire bio definitiva.
- Inserire copertina pubblicazione principale.
- Pubblicare su Cloudflare Pages.

## Fase 2 — Rafforzamento contenuti

- Aggiungere 2–3 articoli reali.
- Raffinare schede corso.
- Aggiungere progetti principali.
- Inserire collegamenti esterni.

## Fase 3 — Risorse

- Aggiungere sezione risorse.
- Creare template scaricabili.
- Creare glossario intelligence.
- Aggiungere bibliografie ragionate.

## Fase 4 — CMS opzionale

- Valutare Decap CMS o altra soluzione Git-based.
- Creare una pagina `/admin`.
- Collegare autenticazione GitHub/OAuth.
